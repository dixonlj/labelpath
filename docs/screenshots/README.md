# Screenshots

These images are captures of the running local UI (`python -m labelpath serve --port 8765`), not mockups.

The file `apixaban-aspirin.png` was first captured from the Linux dry-run box with a headless browser, after the server loaded http://127.0.0.1:8765/?demo=1 and the apixaban → aspirin paths were on the page. Recapture on a Mac if you want a macOS window chrome for Devpost:

1. In `~/Projects/labelpath`, with the venv active, run `python -m labelpath serve --port 8765`.
2. Open http://127.0.0.1:8765/?demo=1 (or click **Try: apixaban → aspirin**).
3. Wait until the path list and diagram appear.
4. Take a screenshot of the window and replace this file, or add a clearly named additional file here.

The page always shows `Educational only, not medical advice.` and the openFDA attribution. Do not crop those out of a submission screenshot.
